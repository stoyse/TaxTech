1. Einführung

Diese Dokumentation beschreibt die Schritte zur Nutzung der generischen Rechnungseingangslösung. Sie führt den Anwender durch den Prozess des Rechnungsimports, der sachlichen und steuerlichen Prüfung, der Freigabe, der Zurückweisung und der Weiterleitung zum Hauptbuch. Ziel ist es, den Anwendern eine klare und detaillierte Anleitung zu bieten, um die Effizienz und Genauigkeit im Umgang mit Rechnungen zu erhöhen.

2. Systemanforderungen

Um die Rechnungseingangslösung nutzen zu können, müssen folgende Systemanforderungen erfüllt sein:

- Betriebssystem: Windows 10 oder höher, macOS 10.14 oder höher
- Internetverbindung: Breitband
- Software: PDF-Reader, Webbrowser (Chrome, Firefox, Safari)
- Benutzerrechte: Administratorrechte für Installation und Konfiguration
3. Import von Rechnungen

## Eingangskanäle

Rechnungen können über verschiedene Kanäle importiert werden:

1. E-Mail: Rechnungen werden als Anhang an eine spezifische E-Mail-Adresse gesendet.
2. Upload-Portal: Rechnungen werden direkt über ein Webportal hochgeladen.
3. API: Rechnungen werden über eine API-Schnittstelle automatisch importiert.
4. Scan: Papierbasierte Rechnungen werden eingescannt und digitalisiert.

## Schritt-für-Schritt Anleitung für jeden Kanal

## 1. E-Mail

1. Öffnen Sie Ihr E-Mail-Programm.
2. Senden Sie die Rechnung als Anhang an die spezifizierte E-Mail-Adresse (z.B. rechnung@unternehmen.com).
3. Die Rechnung wird automatisch in das System importiert.
4. Überprüfen Sie im System, ob die Rechnung korrekt importiert wurde.

## 2. Upload-Portal

1. Öffnen Sie das Webportal in Ihrem Browser.
2. Melden Sie sich mit Ihren Zugangsdaten an.
3. Navigieren Sie zum Bereich "Rechnungsupload".
4. Wählen Sie die Datei aus und klicken Sie auf "Hochladen".
5. Überprüfen Sie im System, ob die Rechnung korrekt hochgeladen wurde.

## 3. API

1. Stellen Sie sicher, dass Ihre Software die API-Schnittstelle unterstützt.
2. Konfigurieren Sie die API-Einstellungen gemäß der Dokumentation.
3. Rechnungen werden automatisch importiert, sobald sie verfügbar sind.
4. Überprüfen Sie im System, ob die Rechnung korrekt importiert wurde.

## 4. Scan

1. Legen Sie die Papierrechnung in den Scanner.
2. Scannen Sie die Rechnung und speichern Sie sie als PDF.
3. Laden Sie die PDF-Datei über das Upload-Portal hoch.
4. Überprüfen Sie im System, ob die Rechnung korrekt hochgeladen wurde.

## 4. Sachliche und steuerliche Prüfung

Sachliche Prüfung

Die sachliche Prüfung umfasst die Überprüfung der Rechnungsdaten und den Abgleich mit

Bestellungen und Lieferscheinen.

## Schritt-für-Schritt Anleitung:

1. Überprüfung der Rechnungsdaten:
2. o Öffnen Sie die importierte Rechnung im System.
3. o Stellen Sie sicher, dass alle relevanten Daten wie Rechnungsnummer, Datum, Betrag und Lieferant korrekt sind.
4. o Überprüfen Sie die Positionen und Mengen auf der Rechnung.

## 2. Abgleich mit Bestellungen:

- o Vergleichen Sie die Rechnung mit den entsprechenden Bestellungen und Lieferscheinen.
- o Stellen Sie sicher, dass die gelieferten Waren oder Dienstleistungen den bestellten entsprechen.
- o Überprüfen Sie, ob die Preise und Mengen übereinstimmen.

## Steuerliche Prüfung

Die steuerliche Prüfung umfasst die Überprüfung der korrekten Berechnung der Mehrwertsteuer und der Steueridentifikationsnummer des Lieferanten.

## Schritt-für-Schritt Anleitung:

1. Mehrwertsteuer:
2. o Überprüfen Sie die korrekte Berechnung der Mehrwertsteuer auf der Rechnung.
3. o Stellen Sie sicher, dass der Mehrwertsteuersatz korrekt angewendet wurde.
2. Steueridentifikationsnummer:
5. o Stellen Sie sicher, dass die Steueridentifikationsnummer des Lieferanten korrekt ist.
6. o Überprüfen Sie, ob die Steueridentifikationsnummer gültig ist.

## 5. Freigabeprozess

Nach erfolgreicher Prüfung wird die Rechnung zur Freigabe weitergeleitet.

## Schritt-für-Schritt Anleitung:

1. Freigabeanforderung:
2. o Stellen Sie eine Freigabeanforderung im System.
3. o Geben Sie alle relevanten Informationen zur Rechnung an.

## 2. Benachrichtigung:

- o Der zuständige Mitarbeiter wird über die Freigabeanforderung benachrichtigt.
- o Der Mitarbeiter erhält eine E-Mail oder eine Benachrichtigung im System.
3. Freigabe:
- o Der Mitarbeiter prüft die Rechnung und gibt sie frei.
- o Die Freigabe erfolgt durch Klicken auf die Schaltfläche "Freigeben" im System.
4. Dokumentation:
- o Die Freigabe wird im System dokumentiert.
- o Alle relevanten Informationen zur Freigabe werden gespeichert.

## 6. Zurückweisung von Rechnungen

Falls eine Rechnung fehlerhaft ist, kann sie zurückgewiesen werden.

## Schritt-für-Schritt Anleitung:

1. Fehleridentifikation:
2. o Identifizieren Sie den Fehler in der Rechnung.
3. o Überprüfen Sie die Rechnungsdaten und die sachliche und steuerliche Prüfung.
2. Zurückweisungsgrund:
5. o Geben Sie den Grund für die Zurückweisung im System an.
6. o Wählen Sie aus den vordefinierten Gründen oder geben Sie einen individuellen Grund an.
3. Benachrichtigung:
8. o Der Lieferant wird über die Zurückweisung informiert.
9. o Der Lieferant erhält eine E-Mail oder eine Benachrichtigung im System.
4. Korrektur:
11. o Der Lieferant korrigiert die Rechnung und sendet sie erneut.
12. o Überprüfen Sie die korrigierte Rechnung im System.

## 7. Weiterleitung zum Hauptbuch

Nach der Freigabe wird die Rechnung zum Hauptbuch weitergeleitet.

## Schritt-für-Schritt Anleitung:

1. Export:
2. o Exportieren Sie die freigegebene Rechnung aus dem System.
3. o Wählen Sie das Format für den Export (z.B. CSV, XML).
2. Import ins Hauptbuch:
5. o Importieren Sie die Rechnung in das Hauptbuch.
6. o Verwenden Sie die Importfunktion des Hauptbuchs.
3. Buchung:
8. o Die Rechnung wird im Hauptbuch verbucht.
9. o Überprüfen Sie die Buchung im Hauptbuch.

## 8. Häufig gestellte Fragen (FAQ)

Frage: Was passiert, wenn eine Rechnung nicht korrekt importiert wird? Antwort: Überprüfen Sie die Eingangskanäle und stellen Sie sicher, dass die Datei korrekt formatiert ist. Bei anhaltenden Problemen wenden Sie sich an den Support.

Frage: Wie kann ich eine Rechnung erneut zur Prüfung senden? Antwort: Öffnen Sie die Rechnung im System und wählen Sie die Option "Erneut prüfen".

Frage: Wie kann ich den Status einer Rechnung überprüfen? Antwort: Öffnen Sie die Rechnung im System und überprüfen Sie den Status im Rechnungsdetails-Bereich.
